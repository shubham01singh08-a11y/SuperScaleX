# SuperScaleX ⚡ | Digital Growth Engine & 3-Pillar Ecosystem

> High-converting web architecture, autonomous AI revenue workflows, and algorithmic performance acquisition engineered to scale brands past revenue plateaus.

---

## 🚀 Overview

SuperScaleX is built with a modern **"Antigravity"** visual theme:
- Levitating glassmorphic cards and 3D parallax micro-interactions.
- Zero-latency responsive performance (<800ms load times).
- Interactive 90-day ROI calculator & multi-step revenue diagnostic engine.
- Direct Cloud Firestore integration with offline/demo simulation fallback.

---

## 🛠️ Tech Stack

- **Frontend:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 (Glassmorphism, Neon glow gradients, Antigravity float keyframes)
- **Icons:** Lucide React
- **Confetti:** Canvas Confetti
- **Backend / Database:** Google Cloud Firestore (Firebase SDK v11)
- **Security:** Hardened Cloud Firestore Security Rules (`firestore.rules`)

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Firebase (Optional for Live Mode)
Copy `.env.example` to `.env` and fill in your Firebase project credentials from the [Firebase Console](https://console.firebase.google.com/):
```env
VITE_FIREBASE_API_KEY=YOUR_API_KEY
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your-sender-id
VITE_FIREBASE_APP_ID=your-app-id
```

> **Note:** If no credentials are provided, SuperScaleX automatically activates **Simulated / Demo Mode** with instant local persistence and zero setup needed!

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
